# 스틸119 홈페이지 프런트엔드

ERP와 분리된 정적 홈페이지 시안입니다. `index.html`을 로컬 정적 서버로 열면 됩니다.

```powershell
cd public-site
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다. 백엔드, Docker Compose, 도메인 설정에는 아직 연결하지 않았습니다. 환율·뉴스·광고는 자리 표시이며 문의 폼은 서버로 데이터를 전송하지 않습니다. ERP 및 카카오톡 버튼은 실제 주소가 확정되면 연결할 수 있습니다.

회사소개 페이지는 `http://localhost:4173/company.html`에서 확인할 수 있습니다. 소개 문구는 steel119.com의 공개 정보와 현재 ERP 메뉴 구성을 기준으로 작성했습니다. 사용자 요청에 따라 실제 데이터가 표시된 ERP 대시보드 및 가공 최적화 화면을 캡처해 사용합니다. 캡처는 촬영 당시의 정적 이미지이며 실시간 연동이 아닙니다. 최적화 화면은 실제 대기 품목을 불러와 계산한 결과로, 임시저장이나 계획 확정은 실행하지 않았습니다.

AI ERP 전용 소개는 `http://localhost:4173/erp.html`입니다. 대시보드·거래처 원장·AI 가공 최적화의 실제 화면과 설명을 제공합니다. 요금은 월 기본료 200,000원 + 사용자 1인당 월 5,000원이며, 사용자 수에 따른 월 요금 계산기는 브라우저에서 동작합니다.
