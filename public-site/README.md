# 스틸119 홈페이지 (정적 시안)

ERP와 분리된 정적 홈페이지입니다. 백엔드·도메인에는 아직 연결하지 않았습니다.

```powershell
cd public-site
python -m http.server 4173
```

http://localhost:4173 접속

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 메인: 한반도 도트맵 + 실시간 피드(예시), 통계 카드, 재고119 카드 슬라이드 + 간편문의, 제철사 로고 마퀴, 특징 카드, AI ERP 쇼케이스(5초 자동 전환), 포토 밴드, 도입 지원, 뉴스, CTA |
| `company.html` | 회사소개, 처리 4단계, 취급 품목, 사업 영역 |
| `erp.html` | AI ERP: AI 주문서 인식 3단계 애니메이션(실제 인식 결과 화면), 기능 카드, 가공 추천조합 카드, 화면 쇼케이스, 요금 계산기(월 200,000원 + 1인당 5,000원) |
| `inquiry.html` | 발주 문의 폼(자재/ERP/광고 유형, 발주서 첨부) |

공통: `site.css`/`site.js`(기본), `site2.css`/`site2.js`(v2 레이아웃·애니메이션). 기존 시안은 `_legacy/`에 보관.

## 연결 전 상태 (자리 표시)
- 폼은 서버로 전송하지 않습니다(안내 토스트만 표시).
- 환율·뉴스·광고·실시간 피드·재고119 카드는 예시입니다. 통계 숫자는 steel119.com 실시간 현황(2026.11) 기준.
- ERP 로그인·카카오톡 채널 주소, 푸터의 주소·사업자번호·대표자는 확정 후 입력.
- 제철사 로고(POSCO·현대제철·동국제강·KG스틸)는 SVG로 근사 재현한 워드마크입니다. 각 사 공식 로고 파일로 교체를 권장합니다 (`site2.js`의 `logos` 배열).

## ERP 화면 캡처
`assets/erp2-*.png`, `assets/erp3-*.png`는 실제 ERP(2배 해상도) 캡처를 잘라낸 것으로 실제 거래처명이 포함됩니다. `erp2-ai-result.png`는 시연용 가상 주문서(`assets/sample-order.png`, (주)샘플건설)를 실제로 AI 분석한 결과입니다.
